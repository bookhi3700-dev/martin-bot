# 마틴봇 — 업비트·빗썸 마틴게일 자동매매

1만 원으로 사고, 평단가(또는 직전 매수가)에서 5% 떨어질 때마다 2배 금액으로 추가 매수하고,
평단가 대비 +10%가 되면 전량 매도하고 다시 1만 원부터 시작하는 프로그램입니다.
모든 숫자는 화면의 **설정** 탭에서 바꿀 수 있습니다.

> **PC가 꺼져 있어도 24시간 돌리려면 → [SERVER.md](SERVER.md) (클라우드 서버 설치)**
> 아래 1번은 내 PC에서 돌리는 방법입니다. 서버와 PC에서 **동시에 돌리지 마세요** (두 곳에서 각각 주문이 나갑니다).

## 1. 설치 (윈도우, 처음 한 번)
1. https://www.python.org/downloads/ 에서 Python 3.11 이상 설치
   - 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 필수
2. 이 폴더를 원하는 곳(예: `C:\martin-bot`)에 압축 해제
3. `START.bat` 더블클릭 → 처음에는 1~2분간 설치 후 브라우저에 대시보드가 열립니다
   (안 열리면 브라우저 주소창에 `http://127.0.0.1:8765`)

> 까만 창을 닫으면 봇도 멈춥니다. PC가 절전모드에 들어가도 멈추니 절전을 꺼 두세요.
> 맥은 터미널에서 `python3 -m pip install -r requirements.txt` 후 `python3 app.py`.

## 2. 사용 순서 (권장)
1. **백테스트** 탭 → 설정을 바꿔가며 과거 1~3년 결과 확인
2. **설정** 탭 → 실행 모드 **모의투자** 로 두고 저장 → **시작**
   (실제 시세로 돌지만 주문은 가상입니다. 며칠 돌려서 동작을 확인하세요)
3. 확신이 들면 API 키를 넣고 **실전** 으로 전환

## 3. API 키 발급
- 업비트: 웹 → 마이페이지 → Open API 관리 / 빗썸: 웹 → 마이페이지 → API 관리
- 권한: **자산조회, 주문조회, 주문하기** 만 체크. **출금은 절대 체크하지 마세요.**
- 허용 IP: 이 PC의 공인 IP 등록 (네이버에 "내 IP" 검색). 집 인터넷 IP가 바뀌면 다시 등록해야 합니다.
- 설정 탭의 **API 키 확인** 버튼으로 잔고 조회가 되는지 먼저 확인하세요.

## 4. 설정 항목
**공통**
| 항목 | 설명 |
|---|---|
| 전체 투입 한도 | 모든 코인 투입금 합계가 이 금액을 넘는 매수는 보류하고 알림 (0 = 제한 없음) |
| 슬리피지 | 백테스트에서 시장가 주문이 불리하게 체결되는 정도 (기본 0.1%) |
| 텔레그램 | 넣으면 매수·매도·오류를 휴대폰으로 알림 |

**코인별** (코인마다 따로 설정, 코인 추가/삭제 가능)
| 항목 | 기본값 | 설명 |
|---|---|---|
| 이 코인 매매 | 켬 | 끄면 그 코인만 매매 중지 (보유분 유지) |
| 1단계 매수금액 | 10,000원 | 최소 5,000원 |
| 마틴 배수 | 2 | 추가 매수할 때마다 곱하는 배수 |
| 단계별 하락폭 | 5 | `5` = 모든 단계 5%, `5,5,7,10,15` = 단계마다 다르게 (모자라면 마지막 값 반복) |
| 하락 기준 | 평단가 | 평단가 기준 / 직전 매수가 기준 |
| 최대 단계 | 6 | 여기까지만 물타기 |
| 익절 수익률 | 10% | 평단가(수수료 포함) 대비, 매도 수수료까지 빼고 남도록 계산 |
| 추적 익절 | 끔 | 켜면 목표 수익 도달 후 고점을 따라가다 고점 대비 N% 빠질 때 매도. 목표가 밑으로 내려오면 바로 매도해 최소 목표 수익은 확보 |
| 자동 재시작 | 켬 | 익절 후 바로 새 사이클 시작 |
| 손절 | 끔 | 켜면 최대 단계 이후 평단 대비 N% 하락 시 전량 매도 |

**백테스트**: "현재 설정으로 실행" 또는 "여러 설정 비교"(하락폭·익절·단계·배수·추적 익절 후보를 넣으면 모든 조합을 계산해 표로 비교, 행을 누르면 그 설정 적용).
"그냥 보유했다면" 수익률과도 비교해 보여줍니다.

## 5. 꼭 알아둘 점
- **최대 단계를 다 쓴 뒤 계속 떨어지면 큰 금액이 물린 채로 멈춥니다.** 이것이 마틴 방식의 가장 큰 위험입니다.
  백테스트의 "최악의 평가손실"과 "미청산 포지션"을 반드시 보세요.
- 원화 잔고는 최대 단계까지 필요한 금액 + 여유분을 넣어두세요. 잔고가 부족하면 매수가 실패하고 알림이 옵니다.
- 봇은 **자기가 산 수량만** 팝니다. 같은 계좌에서 따로 산 코인은 건드리지 않습니다.
- 거래소 앱에서 봇 코인을 직접 팔았다면, 현황 탭 해당 코인의 **기록 초기화**를 눌러주세요.
- 주문은 나갔는데 체결 확인이 안 되면 그 코인은 **일시정지**됩니다 (중복 매수 방지). 거래소 앱에서 확인 후 **재개**를 누르세요.
- 봇이 멈췄다 다시 켜져도 단계·평단가는 `data/` 폴더에 저장돼 있어 이어서 진행합니다.
- 이 프로그램은 수익을 보장하지 않으며, 투자 판단과 결과는 본인 책임입니다.

## 6. 파일
- `app.py` 대시보드 서버 / `bot.py` 자동매매 실행 / `strategy.py` 매매 규칙

- `data/trades_*.csv` 체결 기록 (엑셀로 열림)
